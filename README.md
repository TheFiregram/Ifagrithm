# IFAGRITHM

Web3 research and intelligence website built with Next.js and React.

## Development

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

The static website is exported to `out/`. Vercel uses the included configuration. The main branch is the production source.

The site includes dark and light themes, transparent brand assets, a scroll-reactive logo backdrop, four service panels, automatic research stages, and an email enquiry form. The form opens the visitor’s email app for review and sending.
